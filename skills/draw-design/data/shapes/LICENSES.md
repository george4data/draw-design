# Shape catalog: sources and terms

`families.json` and `<family>.json.gz` are generated by `scripts/build-shape-catalog.py`. Don't edit them by hand.

## Source

- **Index:** [`jgraph/drawio-mcp`](https://github.com/jgraph/drawio-mcp) `shape-search/search-index.json`, Apache License 2.0. The commit is recorded in `families.json` (`source.commit`). jgraph generates the index from draw.io's own sidebar definitions ([`jgraph/drawio`](https://github.com/jgraph/drawio), Apache-2.0).
- **Content:** the catalog stores each shape's draw.io style string with a title and search tags.
  - Most families only **reference** stencils and images that ship inside draw.io (`shape=mxgraph.aws4.*`, `image=img/lib/azure2/*`). draw.io renders those itself.
  - The `gcp` family is different: its icons are embedded SVG data URIs, so the catalog **contains** those images.
- **Verification:** every entry was rendered with draw.io Desktop. Entries that did not draw were dropped. `families.json` records the version used (`verifiedWith`).

## Terms

- draw.io's stencil licence (`src/main/webapp/stencils/LICENSE` in jgraph/drawio) restricts the use of its icon sets in **Atlassian products** and the Atlassian marketplace. It does not restrict end-user diagram output. draw-design is not an Atlassian product.
- Vendor icons stay the property of their owners and are used here to depict those vendors' services in architecture diagrams, as each vendor's icon guidelines permit:
  - Amazon Web Services: AWS Architecture Icons.
  - Google Cloud: Google Cloud icons.
  - Microsoft Azure: Azure architecture icons.
  - Kubernetes: Kubernetes icons set, CNCF, Apache-2.0.

  Vendor guidelines generally ask that icons not be modified or used to imply endorsement. `iconStyle: mono` is opt-in and recolours icons, so keep the default `vendor` colours for material where that matters, such as anything published under or alongside the vendor's brand. Check the vendor's current guidelines for the exact terms.
